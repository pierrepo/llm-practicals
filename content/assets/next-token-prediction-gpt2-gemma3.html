How a language model writes, one token at a time

A large language model never writes a whole sentence at once. It repeatedly answers one question: given everything so far, what token comes next? This application runs a real language model in your browser, a small one, so you can watch every stage of that loop.

Model

    Prompt

    Tokenize

    The model can't read letters or words. Text is cut into tokens, and each token becomes an integer ID from the vocabulary of the model. Common words are one token, usually including the space before them. Rarer words and long numbers are split into several pieces (dashed). Try typing an unusual word or your name.

    Score every token

    The model gives every token in its vocabulary a score, then turns the scores into probabilities that add up to 100%. Here are the few most likely. A "·" stands for a space at the start of a token. Click a token to add it to the text.

    Key ideas to remember

    One token at a timeThe model has no finished sentence in mind. Every token you read was chosen in its own pass through the pipeline, and a word can take several tokens.
    Probabilities for every tokenEach step produces a probability for every token in the vocabulary, even absurd ones. Most of them are tiny.
    Context is everythingEach new token becomes input for the next step. An early unusual choice can send the whole text down a different path.
    Different models, different tokensEach model has its own vocabulary, so the same text can be split into different tokens. Switch between the models with the same prompt and compare.
    About the models

    Every model runs entirely in your browser through Transformers.js (Apache 2.0 licence) and ONNX Runtime (MIT licence). Nothing you type is sent anywhere. A model is downloaded the first time it is selected; the browser then keeps the files if it is allowed to. Once loaded, a model stays in memory until the page is closed, which makes switching back to it instant.

    At every step the model reads the whole text so far and outputs one score for each token in its vocabulary. The application shows the few most likely. A chatbot would sample from all of them; this application leaves that choice to you. Today's chatbots work the same way, with far bigger models and much more training.

    The tokens you click are fed to the model exactly as they are. If you then edit the text by hand, the whole text is cut into tokens again, and the split can differ slightly from the tokens you clicked.
